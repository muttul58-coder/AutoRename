📁 파일명 일괄 변경기

📖 도움말

1. 무엇을 해주나요?

  • 폴더 이름에서 한글·영문 부분을 행사명으로 추출 (앞뒤 숫자·기호 제거)
  • 사진의 EXIF 촬영 정보를 읽어 가장 빠른 날짜를 추출
  • 폴더명·파일명을 통일된 규칙으로 한꺼번에 변경
  • 파일이 여러 장이면 촬영 순서대로 _1, _2… 연번 부여

2. 사용 순서

  1. 폴더 선택 — 사진이 들어있는 폴더(또는 여러 행사 폴더가 든 상위 폴더)를 드래그하거나 클릭해서 선택
  2. 자동 분석 — 한글 추출과 EXIF 스캔이 자동 진행됩니다 (사진이 많으면 시간이 걸려요)
  3. 입력 필요 항목 채우기 — 한글이 없거나 EXIF 날짜가 없는 폴더만 직접 입력
  4. 미리보기 확인 — 변경 전/후를 표로 비교
  5. 저장 위치 선택 — 원본 덮어쓰기 또는 새 폴더에 복사
  6. 변경 실행 버튼 클릭 → 완료

3. 폴더 구조 (자동 인식)

입력 폴더 안에…처리 방식
파일만 있음선택한 폴더 1개를 행사 폴더로 처리
하위 폴더만 있음각 하위 폴더를 행사 폴더로 처리
둘 다 섞여 있음현재 폴더 + 각 하위 폴더 모두 처리

4. 명명 규칙

폴더명 = 한글(YYYY.MM.DD.)
파일명 = 한글(YYYY.MM.DD.).확장자 (1장)
    또는 한글_연번(YYYY.MM.DD.).확장자 (여러 장)

이름 추출: 폴더명의 첫 한글/영문 글자 ~ 마지막 한글/영문 글자 범위만 사용 (사이의 공백·숫자·기호는 유지, 앞뒤의 숫자·기호는 제거)

날짜 추출 우선순위:

  1. 폴더에 사진이 있으면 → 사진의 EXIF 촬영일 중 가장 빠른 날짜 사용 (영상은 무시)
  2. 폴더에 사진이 없고 영상만 있으면 → 영상의 mvhd 촬영일 중 가장 빠른 날짜 사용 (mp4, mov, m4v 등)
  3. 위 두 가지 모두 실패하면 → 사용자에게 직접 입력 요청

동영상 처리: 이름은 변경하지만 사진이 함께 있을 때는 촬영일 추출 대상이 아닙니다. 사진 뒤에 파일명 알파벳 순으로 배치되어 연번이 부여됩니다.

연번 순서: 사진(EXIF 촬영일 오름차순) → 동영상·기타 파일(파일명 순)

6. 저장 위치

  • 원본 폴더에 덮어쓰기 — 빠르고 디스크 공간 절약. 원본 파일이 그 자리에서 이름만 바뀝니다.
    ⚠ 선택한 최상위 폴더 자체의 이름은 브라우저 제약으로 바꿀 수 없습니다. 안쪽 파일과 하위 폴더만 변경돼요.
  • 새 폴더에 복사 — 원본 보존. 새로 지정한 폴더에 변경된 이름으로 복사본 생성. 최상위 폴더 이름까지 바꾸려면 이 모드를 선택하세요.

7. 자주 묻는 질문

Q. 일부 사진의 날짜가 비어요.
A. EXIF 정보가 없는 사진(스크린샷, 편집된 사진 등)은 자동 추출이 안 됩니다. 입력 단계에서 직접 날짜를 지정해주세요.

Q. 한글이나 영문이 없는 폴더는 어떻게 되나요?
A. 폴더명이 숫자·기호로만 이루어져 있으면 자동 추출이 안 됩니다. 입력 단계에서 이름을 직접 입력하면 됩니다.

Q. 실행 후 되돌릴 수 있나요?
A. 「원본 덮어쓰기」 모드는 되돌릴 수 없습니다. 걱정되면 「새 폴더에 복사」 모드를 사용하세요.

Q. Firefox나 Safari에서 안 돼요.
A. File System Access API는 현재 Chrome / Edge에서만 지원됩니다.

8. ✏ 수동 규칙 모드

상단의 「수동 규칙」 탭에서는 파일명 패턴을 직접 정의할 수 있습니다. 폴더명은 변경하지 않고 파일명만 일괄 변경됩니다.

코드의미예시
%y년 (4자리)2026
%m월 (2자리)05
%d일 (2자리)22
%h시 (2자리)14
%n분 (2자리)30
%s초 (2자리)05
%c폴더별 번호 (1부터)1, 2, 3…
%t유닉스 타임스탬프1747890605
날짜·시간은 사진의 EXIF 촬영일을 기준으로 합니다. EXIF가 없는 파일(영상·문서 등)은 파일 수정일을 사용합니다.
%c가 패턴에 없으면, 같은 이름이 충돌할 경우 자동으로 _1, _2가 붙습니다.

패턴 예시:

이미지 %c → 이미지 1.jpg, 이미지 2.jpg, …
%y-%m-%d_%c → 2026-05-22_1.jpg, 2026-05-22_2.jpg, …
photo_%y%m%d_%h%n%s → photo_20260522_143005.jpg

9. 🔒 개인정보·보안

이 도구는 사진을 인터넷에 업로드하지 않습니다. 모든 처리는 사용자 PC 안에서만 일어납니다.
  • 서버 전송 없음 — 사진·파일·EXIF 정보 어느 것도 외부 서버로 전송되지 않습니다.
  • 로컬 처리 — 브라우저의 File System Access API로 사용자가 선택한 폴더에 직접 접근해서 이름만 변경합니다 (탐색기에서 F2로 이름 바꾸는 것과 같은 방식).
  • EXIF 파싱도 브라우저 메모리 안에서만 일어나고 끝나면 즉시 해제됩니다.
  • GitHub Pages의 역할은 HTML 파일을 내려주는 것뿐 — 그 이후 모든 작업은 사용자 브라우저 안에서 진행됩니다.
  • 권한 범위 — 선택한 폴더 외에는 접근할 수 없습니다. 브라우저가 강제로 차단합니다.
  • 완전 오프라인 사용 가능 — 페이지를 한 번 열면 그 뒤로 인터넷을 끊어도 동작합니다.

개발자 도구(F12) → Network 탭을 열어두고 작업하면 외부로 어떤 데이터도 전송되지 않는 것을 직접 확인하실 수 있습니다.

10. 안전 팁

처음 사용하실 때는 테스트용 폴더로 한 번 돌려본 뒤 본 작업을 진행하세요. 중요한 자료는 작업 전 백업을 권장합니다.
⚠️ 이 도구는 Chrome 또는 Edge 브라우저에서만 작동합니다.
📄 파일명 미리보기:
%y년 %m월 %d일 %h시 %n분 %s초 %c/%cc/%ccc번호 %t유닉스 타임 %f폴더명
※ 날짜·시간은 사진의 EXIF 촬영일(없으면 파일 수정일) 기준입니다.
%c=1, %cc=01, %ccc=001 — 폴더별로 1부터 매겨지는 번호입니다.
%f는 추출된 한글 폴더명. 폴더명은 파일명 패턴에서 카운터(_%c)를 뺀 형식으로 자동 적용됩니다.
