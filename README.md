# 📁 파일명 일괄 변경기 (AutoRename)

폴더 안의 사진·파일 이름을 **「행사명(촬영일자)」** 형식으로 자동 정리하는 웹 도구입니다.

🌐 **바로 사용하기:** [https://muttul58-coder.github.io/AutoRename/](https://muttul58-coder.github.io/AutoRename/)

> ⚠️ **Chrome** 또는 **Edge** 브라우저에서만 작동합니다 (File System Access API 필요).

---

## ✨ 주요 기능

- 🔤 폴더 이름에서 **한글 부분**만 자동 추출
- 📅 사진의 **EXIF 촬영일**을 읽어 가장 빠른 날짜 자동 적용
- 🔢 여러 장이면 촬영 순서대로 **_1, _2…** 연번 부여
- 📂 단일 폴더 / 상위-하위 폴더 구조 자동 감지
- 💾 원본 덮어쓰기 또는 새 폴더에 복사 (원본 보존) 선택
- 🌙 다크 / 라이트 테마
- ❓ 내장 도움말

---

## 📖 사용 방법

1. 위 링크에 접속 (Chrome/Edge)
2. 폴더를 드래그하거나 클릭해 선택
3. 자동 분석 후 **누락 항목만** 직접 입력 (한글이 없거나 EXIF가 없는 경우)
4. 미리보기 확인 → 저장 위치 선택 → **변경 실행**

자세한 내용은 앱 우측 상단 **❓ 도움말** 버튼에서 확인.

---

## 🔧 명명 규칙

| 항목 | 형식 |
|------|------|
| 폴더명 | `한글(YYYY.MM.DD.)` |
| 파일명 (1장) | `한글(YYYY.MM.DD.).확장자` |
| 파일명 (여러 장) | `한글_연번(YYYY.MM.DD.).확장자` |

**예시:**
```
2026_저녁 노을 사진 01  →  저녁 노을 사진(2026.05.02.)
0502 운동회             →  운동회(2026.05.02.)
26.5.2. 봄소풍 1        →  봄소풍(2026.05.02.)
```
