📁 파일명 일괄 변경기LOCAL

📖 도움말

1. 무엇을 해주나요?

  • 폴더 이름에서 한글·영문 부분을 행사명으로 추출 (앞뒤 숫자·기호 제거)
  • 사진의 EXIF 촬영 정보를 읽어 가장 빠른 날짜를 추출
  • 폴더명·파일명을 통일된 규칙으로 한꺼번에 변경
  • 파일이 여러 장이면 촬영 순서대로 _1, _2… 연번 부여

2. 사용 순서

  1. 폴더 선택 — 사진이 들어있는 폴더(또는 여러 행사 폴더가 든 상위 폴더)를 선택
  2. 자동 분석 — 한글 추출과 EXIF 스캔이 자동 진행됩니다 (사진이 많으면 시간이 걸려요)
  3. 입력 필요 항목 채우기 — 한글이 없거나 EXIF 날짜가 없는 폴더만 직접 입력
  4. 미리보기 확인 — 변경 전/후를 표로 비교, 폴더명·날짜 직접 편집 가능
  5. 저장 위치 선택 — 원본 덮어쓰기 또는 새 폴더에 복사
  6. 변경 실행 버튼 클릭 → 완료 후 결과 폴더 바로 열기 가능

3. 폴더 구조 (자동 인식)

입력 폴더 안에…처리 방식
파일만 있음선택한 폴더 1개를 행사 폴더로 처리
하위 폴더만 있음각 하위 폴더를 행사 폴더로 처리
둘 다 섞여 있음현재 폴더 + 각 하위 폴더 모두 처리

4. ⚙ 자동 규칙

폴더명 = 한글(YYYY.MM.DD.)
파일명 = 한글(YYYY.MM.DD.).확장자 (1장)
    또는 한글_연번(YYYY.MM.DD.).확장자 (여러 장)

이름 추출: 폴더명의 첫 한글/영문 글자 ~ 마지막 한글/영문 글자 범위만 사용 (사이의 공백·숫자·기호는 유지, 앞뒤의 숫자·기호는 제거)

날짜 추출 우선순위:

  1. 폴더에 사진이 있으면 → 사진의 EXIF 촬영일 중 가장 빠른 날짜 사용 (영상은 무시)
  2. 폴더에 사진이 없고 영상만 있으면 → 영상의 mvhd 촬영일 사용 (mp4, mov, m4v 등)
  3. 위 둘 다 실패하면 → 사용자에게 직접 입력 요청 또는 미리보기에서 직접 입력

5. 변환 예시

2026_저녁 노을 사진 01 → 저녁 노을 사진(2026.05.02.)
0502 운동회 → 운동회(2026.05.02.)
26.5.2. 봄소풍 1 → 봄소풍(2026.05.02.)
IMG_0001.jpg, IMG_0002.jpg
→ 저녁 노을 사진_1(2026.05.02.).jpg

6. ✏ 수동 규칙 모드

상단의 「수동 규칙」 탭에서는 파일명 패턴을 직접 정의할 수 있습니다. 폴더명은 그 패턴에서 카운터(_%c)를 자동으로 뺀 형식으로 같이 적용됩니다.

코드의미예시
%y년 (4자리)2026
%m월 (2자리)05
%d일 (2자리)22
%h시 (2자리)14
%n분 (2자리)30
%s초 (2자리)05
%c / %cc / %ccc폴더별 번호 (자릿수)1 / 01 / 001
%t유닉스 타임스탬프1747890605
%f추출된 한글 폴더명추억여행
날짜·시간은 사진의 EXIF 촬영일(없으면 파일 수정일) 기준입니다. 미리보기에서 폴더별로 날짜·폴더명을 직접 편집할 수 있고, 편집한 값은 패턴이 바뀌어도 유지됩니다.

패턴 예시:

%f_%ccc(%y.%m.%d.) → 폴더: 추억여행(2026.05.05.)
→ 파일: 추억여행_001(2026.05.05.).jpg
(%y.%m.%d.)%f_%ccc → 폴더: (2026.05.05.)추억여행
→ 파일: (2026.05.05.)추억여행_001.jpg
photo_%y%m%d_%h%n%s → photo_20260522_143005.jpg

7. 저장 위치

  • 원본 폴더에 덮어쓰기 — 빠르고 디스크 공간 절약. 원본 파일이 그 자리에서 이름만 바뀝니다. 최상위 폴더 이름까지 변경됩니다.
  • 새 폴더에 복사 — 원본 보존. 새로 지정한 폴더에 변경된 이름으로 복사본 생성.

8. 자주 묻는 질문

Q. 일부 사진의 날짜가 비어요.
A. EXIF 정보가 없는 사진(스크린샷, 편집된 사진 등)은 자동 추출이 안 됩니다. 미리보기에서 폴더별 날짜 input으로 직접 지정해주세요.

Q. 한글이나 영문이 없는 폴더는 어떻게 되나요?
A. 폴더명이 숫자·기호로만 이루어져 있으면 자동 추출이 안 됩니다. 입력 단계에서 이름을 직접 입력하거나, 미리보기 폴더명을 직접 편집하면 됩니다.

Q. 실행 후 되돌릴 수 있나요?
A. 「원본 덮어쓰기」 모드는 되돌릴 수 없습니다. 걱정되면 「새 폴더에 복사」 모드를 사용하세요.

9. 🔒 개인정보·보안

이 도구는 사진을 인터넷에 업로드하지 않습니다. 모든 처리는 사용자 PC 안에서만 일어납니다.
  • 완전 로컬 처리 — Python의 os/shutil·Pillow 모듈을 사용해 사용자 PC 내에서만 파일을 다룹니다.
  • 서버 전송 없음 — 사진·파일·EXIF 정보 어느 것도 외부로 전송되지 않습니다.
  • 인터넷 불필요 — 최초 설치(.venv 의존성 설치) 외에는 오프라인에서도 동작합니다. .exe 빌드 후엔 Python도 필요 없습니다.
